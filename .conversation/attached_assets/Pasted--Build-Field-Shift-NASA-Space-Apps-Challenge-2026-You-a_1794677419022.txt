# Build Field Shift — NASA Space Apps Challenge 2026

You are a senior full-stack engineer, agricultural software architect, and UI/UX designer.

Build a professional, functional web application called **Field Shift**, created for the 2026 NASA Space Apps Challenge: "Field Shift: Adapting Farms with NASA Data."

## 1. Project Vision

Field Shift is an agricultural decision-support platform that helps farmers understand environmental conditions and compare crop-rotation strategies.

The application must combine:
- NASA Earth observation data
- Local climate and soil characteristics
- Farmer-provided information
- Verified crop requirements
- Agricultural rotation rules
- A future trained machine-learning model

The goal is to help farmers explore strategies that may improve soil health, conserve water, reduce environmental risks, and strengthen agricultural resilience.

It must support worldwide farm locations.

The software must be a real, functional application rather than a static design demonstration.

## 2. Technology Stack

Use:
- React + TypeScript
- Tailwind CSS
- FastAPI with Python for the backend
- PostgreSQL for persistent data
- Leaflet + OpenStreetMap for mapping
- Recharts for charts
- RESTful backend APIs

Organize the code into clearly separated frontend, backend, data-ingestion, recommendation, and machine-learning modules.

Configure the app to run reliably in the Replit environment.

## 3. Design Requirements

Create a modern, premium agricultural intelligence interface.

Visual identity:
- Deep forest green
- Sage green
- Earth tones
- Clean cream/off-white backgrounds
- Elegant typography
- Professional data visualization
- Rounded cards
- Subtle animations
- Responsive desktop, tablet, and mobile layouts
- Accessible colors and keyboard-friendly controls

Create a distinctive Field Shift identity with an original logo and professional branding.

The design should feel like a real precision-agriculture platform, not a generic AI chatbot.

## 4. Main Pages

### Homepage
Create a compelling landing page explaining:
- The environmental challenges farmers face
- How NASA satellite observations help understand agricultural conditions
- How Field Shift supports crop-rotation planning
- The platform's features
- A prominent "Analyze My Farm" action

### Farm Selection
Create an interactive global map.

Users must be able to:
- Search for a country, city, or geographic area
- Click on the map to choose a farm location
- Enter coordinates manually
- Draw a field boundary if they know its shape
- View and confirm the selected location

Store the latitude, longitude, and optional polygon geometry.

Include four initial case-study locations:
1. Irbid, Jordan
2. Al Ain, Abu Dhabi, UAE
3. Colusa, California, USA
4. Stuttgart, Arkansas, USA

Do not restrict users to these four locations.

### Farm Information
After selecting a location, show a simple farmer questionnaire.

Collect:
- Current crop
- Previous crop or crop history
- Irrigation availability: rainfed, limited irrigation, or fully irrigated
- Soil texture/type, if known
- Soil moisture, if measured, with clear units
- Soil pH, optional
- Farm size, optional
- Water availability constraints
- Primary goal: conserve water, improve soil health, improve productivity, or reduce risk

Do not require users to know technical satellite measurements.

### Environmental Dashboard
Create a dashboard containing:
- Geographic location
- Historical rainfall chart
- Historical temperature chart
- Monthly climate profile
- Heat exposure indicators
- Available soil and vegetation indicators
- Climate data source and date range
- Missing-data warnings

Do not display fictional values as actual measurements.

### Crop Rotation Planner
Create an interface for:
- Displaying the existing crop rotation
- Comparing two possible alternative strategies
- Inspecting water suitability
- Inspecting soil-health potential
- Understanding environmental risks
- Viewing sources and limitations

The recommendation engine will be implemented in a later stage.

### AI Explanation Panel
Create a section where an AI assistant will eventually explain environmental patterns and recommendation results.

For now, do not claim an AI model is trained or operational.

## 5. Database

Create persistent database models for:
- Farm locations and profiles
- Environmental observations
- Data sources and provenance
- Crop definitions
- Crop requirements
- Crop rotation strategies
- Model versions
- Recommendation results

Include database migrations.

## 6. Development Requirements

- Implement functional frontend navigation.
- Implement backend routes for saving and retrieving farm profiles.
- Validate user inputs.
- Handle loading, API failure, and empty-data states.
- Never invent NASA measurements or agricultural recommendations.
- Do not show made-up suitability percentages.
- Keep secrets and external API credentials on the server only.
- Add a README explaining setup and project structure.

## 7. Deliverable

Complete the website foundation, interactive map, farm-profile workflow, database setup, and dashboard components.

The app must run successfully in Replit.

At the end, explain which features are implemented, which are placeholders, and which require real data or an ML model.

Do not start training any model in this stage.
